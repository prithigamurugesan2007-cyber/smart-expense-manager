
# 💰 Smart Expense Manager & Financial Tracker

A personal finance management web application designed to help users organize their income, expenses, monthly budgets, savings goals, and financial activities in one place.

## 📌 Project Overview

**Smart Expense Manager & Financial Tracker** provides a simple and organized interface for monitoring financial activities. It includes a dashboard, transaction management, income and expense records, budget tracking, savings goals, and financial reports.

The project is developed using PHP and modern web technologies and can be run locally using the WAMP Server.

## ✨ Features

- **Dashboard:** View total balance, monthly income, expenses, and savings.
- **Transaction Management:** View, search, filter, and manage transactions.
- **Income Management:** Track different sources of income.
- **Expense Management:** Record and monitor daily expenses.
- **Budget Tracking:** Create monthly budgets and monitor spending.
- **Savings Goals:** Set financial goals and track savings progress.
- **Reports & Analytics:** View financial summaries and visual charts.
- **Settings:** Manage profile details and application preferences.

## 🚀 Installation & Setup

Follow these steps to run the project locally.

### Step 1: Install WAMP Server

Download and install [WAMP Server](https://www.wampserver.com/).

### Step 2: Download the Project

Clone the repository:

```bash
git clone https://github.com/your-username/smart-expense-manager.git
```

### Step 3: Move the Project Folder

Copy the project folder into:

```text
C:\wamp\www\
```

### Step 4: Start WAMP Server

- Open WAMP Server.
- Start Apache.
- Make sure the WAMP server is running.

### Step 5: Open the Application

Open your browser and visit:

```text
http://localhost/smart-expense-manager/
```
