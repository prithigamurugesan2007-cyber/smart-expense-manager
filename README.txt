SMART EXPENSE MANAGER & FINANCIAL TRACKER
=========================================

Frontend-only college project built with PHP, HTML, CSS, and vanilla JavaScript.
It uses sample data and browser localStorage. No database is required.

RUN WITH WAMP
1. Copy the entire smart-expense-manager folder into:
   C:\wamp64\www\smart-expense-manager\
2. Start WAMP Server and wait for the tray icon to turn green.
3. Open this URL in your browser:
   http://localhost/smart-expense-manager/

IMPORTANT
- Do not open index.php directly from File Explorer.
- The website uses Chart.js from a CDN for charts, so an internet connection is needed for charts.
- Demo transactions, budgets, and savings goals are stored in the current browser's localStorage.
- This project is not connected to a real bank account and should not be used for real financial records.
- To reset demo data, open Settings and click Reset all demo data.
